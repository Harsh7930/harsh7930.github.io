# Part A: ES6 Features

This page introduces modern JavaScript syntax with small examples. The result
of each example is shown on the page, and messages are also written to the
browser console.

It includes:

- `let` and `const`
- `var`, arrow functions, and template literals
- array and object destructuring
- spread and rest syntax
- default parameters
- classes, inheritance, static methods, and enhanced object literals
- ES6 import/export modules
- promises with `async`/`await`

## Run the page

The `app.js` file imports `math.js`, so open the page through a local server.
Start the server in the `Exp 07 & 08` folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000/Part-A-ES6/` in a browser. On Windows, you
can use `py -m http.server 8000` if `python` is not recognized.
