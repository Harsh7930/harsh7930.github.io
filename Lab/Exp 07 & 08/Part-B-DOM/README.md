# Part B: DOM Manipulation

This page demonstrates how JavaScript can select and update HTML elements.
Start the local server from the `Exp 07 & 08` folder, then visit
`http://localhost:8000/Part-B-DOM/`.

Try the buttons and input to see these examples:

- Selecting elements with `getElementById`, `getElementsByClassName`, `getElementsByTagName`, `querySelector`, and `querySelectorAll`
- Changing content with `textContent`, `innerText`, and `innerHTML`
- Reading, changing, and removing attributes
- Changing an inline style and toggling a CSS class with `classList`
- Creating, adding, and removing elements with `createElement`, `appendChild`, `append`, and `remove`
- Traversing parent, child, and sibling elements

The `innerHTML` example uses fixed, trusted content. Use `textContent` for
user-entered text so the browser treats it as text rather than HTML.
