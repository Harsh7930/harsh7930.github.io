Basic HTML, CSS, and JavaScript Structure

Before diving into jQuery, it is important to understand the basic structure of a web page:

<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
    <style>
        body { font-family: Arial; }
    </style>
</head>
<body>
    <div id="content">Hello World!</div>

    <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
    <script>
        $(document).ready(function() {
            $("#content").css("color", "blue");
        });
    </script>
</body>
</html>

jQuery simplifies JavaScript operations, making it easier to select elements, handle events, and create animations.

Practice Questions

1. Select all paragraphs and change their text color to blue

$("p").css("color", "blue");

2. Select an element with id "main" and hide it

$("#main").hide();

3. Change the HTML content of a div with class "container"

$(".container").html("New content");

4. Add a click event to a button that shows an alert

$("button").click(function() {
    alert("Button clicked!");
});

5. Create a fade-in effect for a hidden div

$("div").fadeIn();

6. Add a class to an element on button click

$("button").click(function() {
    $("#element").addClass("active");
});

7. Make an AJAX request to get data from a JSON API

$.ajax({
    url: "https://jsonplaceholder.typicode.com/posts/1",
    method: "GET",
    success: function(data) {
        console.log(data);
    }
});

8. Create a slide toggle effect for a menu

$("#menu").slideToggle();

9. Validate a form before submission

$("form").submit(function(event) {
    if ($("#name").val() === "") {
        event.preventDefault();
        alert("Name is required");
    }
});

10. Create a simple image slider

let index = 0;
const images = ["img1.jpg", "img2.jpg", "img3.jpg"];

setInterval(function() {
    $("#slider").attr("src", images[index]);
    index = (index + 1) % images.length;
}, 2000);
