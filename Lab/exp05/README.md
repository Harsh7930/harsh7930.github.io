# Experiment 05: jQuery Learning Path

## Aim
To understand the basic concepts of jQuery and how it can be used for DOM selection, event handling, animation, and AJAX in web development.

## Objectives
- Learn the basic structure of a web page using HTML, CSS, and JavaScript.
- Understand how jQuery simplifies JavaScript code.
- Practice jQuery selectors and DOM manipulation.
- Learn event handling and effects.
- Understand the use of AJAX with JSON data.

## Tools Required
- Modern web browser
- Internet connection for the jQuery CDN
- VS Code or any text editor

## Project Structure
```text
exp05/
├── index.html
├── styles.css
├── app.js
├── README.md
└── assets/
    ├── forest.svg
    ├── mountains.svg
    └── ocean.svg
```

## Steps to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. If needed, run a local server:

```powershell
py -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Concepts Covered
- Selectors
- DOM Manipulation
- Event Handling
- Effects & Animations
- AJAX

## Practice Questions Included
1. Select all paragraphs and change their text color to blue.
2. Select an element with id `main` and hide it.
3. Change the HTML content of a div with class `container`.
4. Add a click event to a button that shows an alert.
5. Create a fade-in effect for a hidden div.
6. Add a class to an element on button click.
7. Make an AJAX request to get data from a JSON API.
8. Create a slide toggle effect for a menu.
9. Validate a form before submission.
10. Create a simple image slider.

## Expected Output
The browser page should display:
- a proper jQuery learning-path layout,
- concept cards for selectors, DOM, events, effects, and AJAX,
- ten practice questions,
- answer sections that open when the user clicks the button.

## Notes
This experiment helps students understand how jQuery makes JavaScript work simpler for the browser.

## Student Summary
This experiment demonstrates the importance of jQuery in front-end web development. It covers selection of elements, changing styles, handling button clicks, adding animation effects, and using AJAX for fetching external data.
